# trading-strategy

Version 0.2.0 adds MarketFrame/SignalRecord, the SignalModel protocol, reusable
close-price features, an explicit registry/engine adapter, and purged offline
forward-return studies. `aegis-signals list` lists built-ins and `aegis-signals demo`
runs a clearly synthetic workflow. See SIGNAL_DEVELOPMENT.md in the repository.
No broker or execution dependency is introduced.

Pure signal generation.

Import from `trading_strategy`. This library has its own version and wheel. Install with sibling dependencies from the framework wheelhouse; these packages are local and have not been published to PyPI.
